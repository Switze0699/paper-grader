# 地理 AI 阅卷训练器（paper_grader）

> 让 AI 当一次"虚拟考官"：它出题、模拟学生答卷、逐采分点判分，
> 你在电脑上跟着判一遍，然后看两边差多少。

一个给高中地理老师用的**阅卷训练工具**。不是拿来替人批作业的，是拿来
**让你和 AI 考官对同一份卷子练手、找差距**的。

---

## 它解决什么问题

批改作业最费时间，也最难进步——批多了会麻木。���个工具把这件事拆开：

1. **AI 出题**（带评分细则），你确认题目合不合适
2. **AI 扮演 5 个水平档的学生**（优秀/良好/中等/薄弱/很差）写出答卷
   —— 它们**看不到**评分细则，是真的在"考试"，所以会漏点、会偏差
3. **AI 逐采分点判分**，给出分数、理由、踩点证据
4. **你盲评同一批答卷**（界面不显示 AI 分数，防止被带偏）
5. **报告对比**：你的平均分 vs AI 平均分、偏差、一致率

关键点：**AI 判分不只是给个数，它会把"你写出了这个采分点但没和设问建立连接"
这种话原文写出来** —— 这是最值钱的部分，比分数本身有用。

---

## 效果长什么样

- 答卷用**手写体**渲染（鸿雷拙书，免费商用），一眼就是学生答题卡的样子
- 报告里给出偏差与一致率：偏差 ±1 分以内算吻合，超过就要反思是不是标准理解偏了
- 每次批改记录**耗时**（出题/生成/阅卷各多少秒）+ 用了多少次 API
- 学生答案有**质量闸门**：跑方向（问自然却答经济）、写成残句会被打回重写

## 安装（首次）

需要 **Python 3.11 或更高**（推荐 3.13）。

```bash
# 1. 拉代码
git clone <你的仓库地址>
cd paper_grader

# 2. 建虚拟环境
python -m venv .venv

# 3. 装依赖
#    Windows:
.venv\Scripts\pip install -r requirements.txt
#    macOS / Linux:
.venv/bin/pip install -r requirements.txt

# 4. 配密钥
#    把 .env.example 复制成 .env，把等号后面换成你的智谱 API Key
#    Windows:
copy .env.example .env
#    macOS / Linux:
cp .env.example .env
```

**去哪儿拿 API Key**：打开 <https://open.bigmodel.cn> 登录 → 右上角头像 →
`API Keys` → 新建 → 复制那串形如 `xxxx.yyyy` 的密钥。

> ⚠ **`.env` 已被 `.gitignore` 忽略，不会被提交**。这是你的密钥，别弄丢。

## 启动

### 方式一：网页版（推荐，手机也能用）

```bash
.venv\Scripts\python.exe -m app.server
```

浏览器会自动打开界面。**手机用**：确保手机和电脑连同一个 WiFi，
点右上角绿色的「手机访问」按钮扫二维码即可。

> 关掉黑色窗口 = 服务停止。手机首次打开会显示百分比进度（十几秒），
> 之后就很快了。

### 方式二：打包成 exe（给不熟悉命令行的老师）

```bash
.venv\Scripts\pip install pyinstaller
.venv\Scripts\python.exe -m PyInstaller build_exe.spec --noconfirm
```

生成的 `dist/批改模拟器.exe` 可以拷给任何电脑，**不需要装 Python**。

## 怎么用（界面上点）

| 步骤 | 做什么 |
|---|---|
| ① 配置密钥 | 第一次用，在项目文件夹的 `.env` 里填一次 |
| ② 出题 | 点「让 AI 出一道新题」，看一眼题目和评分细则，不合适就换 |
| ③ 生成 + 阅卷 | 点「确认细则，开始生成答卷并阅卷」，约 1~3 分钟 |
| ④ 你来批改 | 逐份看 AI 判的点，给自己的分数（**此时看不到 AI 分数**） |
| ⑤ 看报告 | 对比你的分和 AI 的分，看偏差和一致率 |
| ⑥ 导出 | 导 Excel，含逐点判定理由和证据 |

## 可以自己改的地方

**改提示词**（这是这个工具最有价值的部分，用记事本就能改，改完重开生效）：

| 文件 | 管什么 |
|---|---|
| `prompts/question.txt` | 怎么出题（难度、题型、地区倾向） |
| `prompts/answer_system.txt` | 学生怎么答题（水平差异、字数、毛病） |
| `prompts/grading_system.txt` | **阅卷标准**（什么叫"命中"、给几分） |
| `prompts/grading_user.txt` | 阅卷时怎么把细则发给 AI |

**改配置** `config.yaml`：

| 配置项 | 作用 |
|---|---|
| `classroom.students` | 一次生成几份答卷（默认 8，试跑改 4，正式用改 40） |
| `classroom.ability_weights` | 五档水平的比例 |
| `question.score_options` | 出题的分值范围 |
| `ui.answer_font` | 答卷字体 |

> 改之前建议先备份一份（复制 `prompts` 文件夹），改坏了复制回来即可。

## 开发者信息

- **技术栈**：Python + Flet（跨平台 GUI，桌面/网页/手机同一套代码）
- **AI 后端**：智谱 GLM（`glm-4.5-air`），OpenAI 兼容接口
- **数据**：本地 SQLite（`data/grader.db`），不上传任何数据
- **代码规模**：约 9200 行，50 个文件
- **测试**：`python tests/test_core.py` / `test_answer_flow.py` / `test_ui.py`

```
core/       业务核心：出题计划、质量闸门、计时、路径
services/   与 AI 交互：请求、提示词装载、生成、阅卷
storage/    本地数据库与 Excel 导出
app/        Flet 界面（screens/ 是各个页面）
prompts/    全部提示词（教师可直接编辑）
tests/      自测脚本
```
