你的任务：从一段**格式不固定的高中地理试题原文**里，提取出结构化字段。

# 铁律（违反任何一条都算失败）

1. **一个字都不许改写。** 题干、材料、采分点，全部**原样照抄**原文里的字。
   - 不要润色、不要补全、不要"纠正"错别字
   - 不要把简短的采分点扩写成完整句子
   - 不要加任何原文里没有的内容
   - 唯一例外：**分值**允许按后面的规则推断，那是数字不是文字

2. **不确定就说不确定。** 宁可把 `ok: false` 填上，也不要瞎猜。

3. **只做"分段"和"切分"，不做"创作"。** 你是在整理别人写好的东西，
   不是在出题。

# 要提取的字段

## stem —— 设问（学生要回答的那句话）
就是"分析……的主要原因""说明……的原因"这类**要求作答的话**。
如果原文设问里带了分值（如"（8分）"），**去掉分值**，分值单独放 max_score。

## material —— 材料
背景文字、数据、图表说明。**没有材料就填空字符串。**

## max_score —— 满分
按顺序判断：
1. 原文设问或材料里明确写了分值（"（8分）""满分8分""本题8分"）→ 用它
2. 否则 → 采分点数量 × 2

## points —— 采分点
从"答案"部分逐条切分出来，**每条一个点**。

常见形态都要能认：
```
1. 河流泥沙量大：珠江流域水土流失导致入海泥沙丰富     ← 编号 + 冒号后半句
1. 河流泥沙量大（2分）                              ← 编号 + 括号分值
①河流泥沙量大  ②径流与潮汐作用  ③地形平缓            ← 圈号，无编号点
- 河流泥沙量大                                      ← 破折号
```

**每点的分值 score**：
- 原文该点后面**明确写了分值**（"（3分）""(1分)"）→ 用写的那个
- 否则 → **一律 2 分**（这是默认规则，不许自己猜别的数）

**每点的 text**：
- 冒号前后都算，但要**去掉分值括号**（`河流泥沙量大：珠江流域水土流失...` 就照抄这句）
- 去掉开头的编号（`1.` `①` `-`）
- **冒号后的内容要保留** —— 那是"为什么"，阅卷时靠它判断学生有没有把因果链写出来

## analysis —— 题目解析
**用你自己的话**写 1~3 句话，说明这道题考什么、学生要答出哪些层次。
这一栏允许你写，不要照抄答案。

## 判分要点的类型
判断这条采分点属于哪一类（阅卷时要区别对待）：

- `"chain"`（因果链型）：需要"条件 → 机制 → 结论"三环齐全，例如
  "径流与潮汐相互作用：洪季径流强，枯季潮汐强"
- `"fact"`（要点罗列型）：只需要答出关键词就得分，例如
  "河流泥沙量大"（后面没有解释为什么）

# 输出格式（严格的 JSON，不要加任何其他文字）

```json
{
  "ok": true,
  "stem": "设问原文（去掉分值）",
  "material": "材料原文，没有就空字符串",
  "has_answer": true,
  "max_score": 8,
  "max_score_source": "written" 或 "inferred",
  "points": [
    {"seq": 1, "text": "采分点原文", "score": 2, "kind": "chain"},
    {"seq": 2, "text": "采分点原文", "score": 2, "kind": "fact"}
  ],
  "analysis": "1~3 句解析",
  "unclear_parts": []
}
```

字段说明：
- `ok`：能不能可靠地提取出完整信息。为 false 时下面的字段可以空着
- `has_answer`：原文**完全没有答案部分**时填 false，此时 points 为空数组，
  max_score 只能靠原文写的分值来定
- `max_score_source`：`written` = 原文写了分值；`inferred` = 按点数×2 推断的
  ⚠ 用户要能看到这个区别，所以务必如实填写
- `unclear_parts`：你觉得哪段文字含义不清、可能提取错了，**写在数组里**
  （比如"材料第二段似乎是另一个问题"）。没有就空数组。
  ⚠ 这里填了内容，`ok` 就该考虑填 false。

# 示例

输入：
```
题目：分析珠江口伶仃洋海岸线向海推进的主要原因。
材料：珠江口伶仃洋海域是典型的河口湾，位于珠江下游，河道宽阔。
答案：
1. 河流泥沙量大：珠江流域水土流失导致入海泥沙丰富
2. 径流与潮汐相互作用：洪季径流强，枯季潮汐顶托明显
3. 地形平缓：河口区坡度小，流速减慢
```

输出：
```json
{
  "ok": true,
  "stem": "分析珠江口伶仃洋海岸线向海推进的主要原因。",
  "material": "珠江口伶仃洋海域是典型的河口湾，位于珠江下游，河道宽阔。",
  "has_answer": true,
  "max_score": 6,
  "max_score_source": "inferred",
  "points": [
    {"seq": 1, "text": "河流泥沙量大：珠江流域水土流失导致入海泥沙丰富", "score": 2, "kind": "chain"},
    {"seq": 2, "text": "径流与潮汐相互作用：洪季径流强，枯季潮汐顶托明显", "score": 2, "kind": "chain"},
    {"seq": 3, "text": "地形平缓：河口区坡度小，流速减慢", "score": 2, "kind": "chain"}
  ],
  "analysis": "本题考查河口海岸线向海推进的泥沙来源与堆积条件，需从泥沙供给、水动力作用和地形坡度三个层面作答。",
  "unclear_parts": []
}
```

# 特别注意

- **材料里不要漏。** 哪怕材料有五六百字，也要**完整照抄**——
  学生答卷要靠它，漏了就没法生成答案。
- 原文如果只有题目和材料、**没有答案**，就 `has_answer: false`，
  不要自己编采分点。
- 原文可能有"参考答案""评分标准""得分点"等各种叫法，
  **都算答案部分**，从里面切采分点。
